# 💎 Трекер Telegram NFT-Подарков и Распределения Лотов

Автоматизированная система мониторинга NFT-подарков Telegram с фильтрацией по категориям, определением доступности личных сообщений (без звёзд/премиума), форумами Telegram и механикой занятия лотов («Занять лот») с защитой от одновременного перехвата.

---

## 🚀 Основной функционал

1. **Непрерывный мониторинг**:
   - Отслеживание новых NFT-подарков, листингов на маркетплейсах и крафта улучшенных подарков за звёзды.
2. **Глубокий анализ владельцев (MTProto + API)**:
   - Ссылка на подарок и актуальная цена на маркете (в GRAM / TON).
   - Определение, можно ли написать владельцу **бесплатно** (проверка настроек Telegram: требует ли контакт звёзды за сообщения или обязательный Telegram Premium).
   - Подсчёт общего количества подарков в профиле.
   - Определение пола владельца (выделение профилей девушек).
3. **5 фильтров и публикация по топикам группы**:
   - 🟢 **Дешёвые подарки**: 1 – 5 GRAM.
   - 🟡 **Средние подарки**: 5 – 20 GRAM.
   - 🔴 **Дорогие подарки**: 20 – 100 GRAM.
   - 🌸 **Подарки девушек**: до 100 GRAM от женских профилей.
   - ✨ **Улучшенные подарки**: скрафченные NFT за звёзды (не выставлены на маркет).
4. **Интерактивные кнопки на каждом сообщении**:
   - 📌 **Занять лот**: присваивает лот себе с кулдауном 5 секунд.
   - 👤 **Профиль владельца**: переход в профиль.
   - ✍🏻 **Написать владельцу**: открытие диалога в 1 клик.
5. **Защита и доставка лотов в ЛС**:
   - При нажатии «Занять лот» карточка моментально уходит пользователю **в личные сообщения от бота**.
   - Сообщение в группе автоматически удаляется (или скрывается), предотвращая перехват контакта другими участниками.
6. **Загрузка и парсинг баз**:
   - Импорт списков контактов через отправку `.txt` файла прямо в диалог с ботом или командой `/add_base`.

## ⚙️ Пошаговая настройка

### Шаг 1. Создание бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) и создайте нового бота командой `/newbot`.
2. Скопируйте полученный **HTTP API Token**.

### Шаг 2. Подготовка рабочей группы
1. Создайте группу в Telegram и переведите её в режим **Форума** (Включить «Темы» / «Topics» в настройках группы).
2. Создайте 5 тем (топиков) под ваши фильтры:
   - *Дешёвые подарки*
   - *Средние подарки*
   - *Дорогие подарки*
   - *Подарки девушек*
   - *Улучшения за звёзды*
3. Добавьте вашего бота в группу и назначьте его **Администратором** (с правами на удаление сообщений и публикацию в темы).

> 💡 **Как узнать ID группы и топиков:**
> Отправьте любое сообщение в нужный топик, скопируйте ссылку на сообщение (`Копировать ссылку на сообщение`).
> Ссылка выглядит так: `https://t.me/c/1234567890/5/42`
> - ID группы: `-1001234567890` (к числу `1234567890` добавляется префикс `-100`).
> - ID топика: `5` (первое число после ID группы).

### Шаг 3. Заполнение файла `.env`
Создайте файл `.env` в папке проекта (на основе `.env.example`):
```env
BOT_TOKEN=ваш_токен_бота_от_botfather
TELEGRAM_GROUP_ID=-1001234567890

TOPIC_CHEAP_ID=2
TOPIC_MEDIUM_ID=3
TOPIC_EXPENSIVE_ID=4
TOPIC_GIRLS_ID=5
TOPIC_UPGRADED_ID=6

CLAIM_COOLDOWN_SECONDS=5
CLAIM_ACTION=delete

# Для глубокой проверки приватности ЛС (звёзды / премиум)
# Получите api_id и api_hash на https://my.telegram.org:
TELEGRAM_API_ID=
TELEGRAM_API_HASH=
```

### Шаг 4. (Опционально) Авторизация Telethon
Если вы указали `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`, выполните однократную авторизацию:
```bash
python auth_session.py
```
Введите номер телефона и код из Telegram. После этого трекер сможет точно определять, включено ли у владельца требование звёзд за сообщения.

## ▶️ Запуск трекера

Запустите систему командой:
```bash
python main.py
```

### Тестирование работы:
1. Зайдите в личные сообщения с вашим ботом и нажмите команду `/start`.
2. Напишите боту команду:
   ```
   /test_lot
   ```
3. Бот мгновенно отправит 5 тестовых лотов в вашу группу (по одному в каждый топик).
4. Нажмите кнопку **📌 Занять лот** в группе:
   - Сообщение удалится из группы.
   - Лот мгновенно прилетит вам в личные сообщения от бота со ссылками на профиль владельца.
   - Если вы нажмете еще раз в течение 5 секунд, бот выдаст предупреждение о кулдауне.
